# Сайт Drift

Одностраничный сайт без сборки: папка со статическими файлами.

## Где что менять
- **`links.json`**: все ссылки на одном месте. Меняйте только этот файл.
  - `githubRepo`: адрес репозитория вида `ваш-логин/drift`. Из него сайт сам строит прямые ссылки на скачивание установщиков Mac и Windows из последнего релиза.
  - `macFile`, `windowsFile`: имена файлов в релизе. Не меняйте их, а новые версии загружайте под теми же именами.
  - `googlePlay`, `ruStore`, `appStore`: ссылки на страницы приложения в магазинах. Пустая ссылка = на карточке «Скоро».
  - `privacyEmail`: почта для вопросов о приватности.
- **`app.js`**: тексты на английском и русском (блок `TEXT` в начале файла).
- **`assets/img/`**: иконка и скриншоты Mac. **`assets/demo/`**: живое демо, его сценарий в `assets/demo/mock.js`.

## Посмотреть у себя
```bash
cd ~/Desktop/Drift-site
python3 -m http.server 8099
```
Откройте http://localhost:8099 (двойным щелчком по `index.html` не откроется: демо-экраны грузятся как отдельные страницы).

Подробная инструкция по публикации: `PUBLISH.md`.
