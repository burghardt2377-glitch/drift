# Как выпустить сайт на Netlify

Схема: **сайт** лежит на Netlify, **установщики** на GitHub Releases (бесплатно, большие файлы, не тратят лимит Netlify), а **ссылки** правятся одним файлом `links.json`.

## 1. GitHub (репозиторий и релиз)
1. Войдите в GitHub из терминала (откроется браузер, вы входите сами):
   ```bash
   gh auth login
   ```
2. Скажите мне, и я создам публичный репозиторий `drift`, загружу сайт и выложу релиз `v1.0.0` с двумя установщиками.

Репозиторий должен быть **публичным**, иначе скачивание установщиков не откроется для посетителей.

## 2. Netlify (сайт)
1. Зайдите на https://app.netlify.com и войдите (можно через GitHub).
2. **Add new project → Import an existing project → GitHub** и выберите репозиторий `drift`.
3. Настройки оставьте как есть: **Build command** пустая, **Publish directory** `.` (точка). Нажмите **Deploy**.
4. Через минуту сайт будет по адресу `что-то.netlify.app`. Имя можно поменять: **Project configuration → Change project name**. Своё доменное имя подключается в **Domain management**.

## 3. Как обновлять ссылки на магазины
1. Откройте репозиторий на GitHub → файл `links.json` → значок карандаша.
2. Вставьте ссылку между кавычками, например `"ruStore": "https://www.rustore.ru/catalog/app/..."`.
3. **Commit changes**. Netlify сам обновит сайт примерно за 30 секунд.

## 4. Как выпустить новую версию установщика
1. GitHub → **Releases → Draft a new release**, новый тег (`v1.0.1`).
2. Загрузите файлы **с теми же именами**: `Drift-macOS-arm64.dmg` и `Drift-windows-x64.zip`.
3. **Publish release**. Кнопки на сайте ведут на «последний релиз», так что ничего больше менять не нужно.

## Что стоит знать
- Установщики без подписи: macOS и Windows покажут предупреждение при первом запуске (как открыть, написано в `GUIDE-publishing.md`).
- Почту в `links.json` замените на свою вместо `hello@example.com`.
- Адрес `https://ваш-сайт/#privacy` можно указывать как ссылку на политику конфиденциальности в магазинах.
